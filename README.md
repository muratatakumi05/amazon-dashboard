# Amazon Dashboard

Amazon Seller Central の Business Report CSV と、Amazon 広告の Sponsored Products CSV をブラウザ内だけで集計するダッシュボードです。アップロードしたファイルはサーバーへ送信されません。

## 起動

```bash
npm start
```

`http://localhost:4173` を開き、2 種類の CSV を選択してください。

## 対応 CSV

- Business Report: 「日付」「注文商品売上」などを含む日本語 CSV、および英語 CSV
- Sponsored Products: 「日付」「広告費」「広告がクリックされてから7日間の総売上高」などを含む日本語 CSV、および英語 CSV
- UTF-8（BOM あり・なし）と Shift_JIS、カンマ区切りとタブ区切り

列名は表記揺れを正規化して判定します。必須の金額列が見つからない場合は、0 として扱わずエラーを表示します。
CSVを読み込むまでは指標を「未読込」と表示し、アップロードした実データだけを集計します。サンプル値やフォールバックの数値は表示しません。
読み込み後は、実際に集計へ使用した列名とデータ行数をファイル名の下に表示します。金額として解釈できない値が含まれる場合も、黙って0へ置き換えず該当行と列をエラー表示します。
両方のCSVに日付列がある場合は対象期間も比較し、一致しなければダッシュボード上で警告します。

## 指標

| 指標 | 計算式 |
|---|---|
| 売上 | Business Report の注文商品売上の合計 |
| 広告費 | Sponsored Products の費用の合計 |
| 広告売上 | Sponsored Products の広告経由売上の合計 |
| ROAS | 広告売上 ÷ 広告費 |
| ACOS | 広告費 ÷ 広告売上 × 100 |
| TACoS | 広告費 ÷ 売上 × 100 |

分母が 0 の比率は、誤解を招く `0` ではなく `—` と表示します。
広告CSVにACOS・ROAS列が含まれていてもその値は平均せず、期間内の広告費合計と広告売上合計から再計算します。

## 実装構成

このリポジトリには Next.js の設定ファイルや `src/app/page.tsx` はなく、依存パッケージを必要としない静的な ES Modules アプリとして構成されています。画面のエントリーポイントは `index.html`、CSV処理は `src/csv.js`、指標計算は `src/metrics.js` です。
